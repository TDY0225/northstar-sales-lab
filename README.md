# Northstar Sales Lab

Phase 2 foundation for a fictional B2B webinar lead-generation portfolio site.

## Routes

- `/` — webinar landing page
- `/follow-up-frameworks` — lead-magnet page
- `/thank-you` — conversion confirmation shell
- `/privacy` — supporting privacy notice

## Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm run build
git diff --check
```

Phase 2 intentionally stops before production HubSpot integration, final analytics, deployment, and full form delivery behavior.
